# 研究方向与题目映射

检索与核实截止 **2026-10-07**。S01–S12为2024–2026一手来源抽样；S13是旋转单元运动学的经典基础来源。这里不声称系统综述、全面覆盖或文献计量热点排名。正式比较前还需要工程领域外部审阅和真实任务试跑。

| 研究方向 | 具体考查 | 题号 | 来源 |
|---|---|---|---|
| 非线性逆向设计与昂贵计算预算 | 曲线误差、同源数据隔离、有限预算可行选点 | 03、04 | S01、S07、S11 |
| TPMS与杆壳/异构连接 | 片状/网络实体区分、混合场、界面与连通性 | 09、10 | S02、S06、S12 |
| 梯度与几何生成有效性 | 连续隐式场不自动保证实体连通、梯度参数继承 | 10、13 | S02、S07 |
| 制造偏差与稳健性 | 名义/成品尺寸、缺陷代理、工艺边界、排粉证据 | 08、11、16、17 | S03、S04、S11 |
| 动态吸能与载荷模式 | SEA/CFE/峰力、拉压差异、动态数据的适用条件 | 02、05 | S04、S05、S08 |
| 有限阵列与均匀化边界 | 每轴N、尺寸拟合、边界条件改变后的外推风险 | 01、06、11 | S05、S08、S10 |
| 多材料和可编程运动学 | 几何与材料标签分离、角度更新、理想铰链限制 | 12、14、15 | S08、S13 |
| 多功能与可制造Pareto | 热力目标、振动带隙、导热与对流差别、缺失压降 | 07、19、20 | S01、S09、S11 |

LAT-18另外考查工程agent交付可靠性，是软件工作流能力题；它与数字制造研究任务有关，但不是声称某篇论文提出了这项幂等/哈希算法。

研究背景与题目真值分开：全部公式和数值fixture为本仓库自编测试合同，不是对文献原始数据的复现。S05的一维双稳态动力学不能变成三维点阵SEA通用定律；S09的固体导热也不能提供未测的压降。S13不代表任意旋转矩形都具有−1泊松比，题目必须给定连接与格距公式。

## v0.2研究挑战与外部参照

LAT-21将自由形/异构设计转为带孔和接口的真实几何任务；LAT-22要求非线性杆系的实际设计求解闭环；LAT-23把多功能约束转为限定模型无解证明和授权改型；LAT-24要求实际损坏网格修复。这些任务单独计分，尚未测量模型区分度。

已有ISO/ASTM方法标准以及MetaBench、MetamatBench研究协议另见[已有标准与公开基准](STANDARDS.md)。本库暂未复现外部数据集；13条研究来源卡、外部方法标准和公开benchmark引用分别记录，不能混称为本项目已完成的实验依据。
