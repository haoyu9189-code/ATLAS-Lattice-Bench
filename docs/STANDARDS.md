# 已有试验标准与公开研究基准

核实日期：**2026-10-07**。lattice研究已有实验/制造方法标准，也已有机器学习研究benchmark。它们分别约束测量方法、数据与评估协议；不能把自拟agent分数称为行业认证。

本次只查阅标准发布方公开的版本信息、摘要和适用范围，未取得或逐条审核付费标准全文。这里是选用方法的映射，不是符合性声明；不复制或分发付费标准正文。

## 物理试验与增材制造

| 标准及核实版本 | 用途 | 本题库应如何处理 |
|---|---|---|
| [ISO 13314:2011](https://www.iso.org/standard/53669.html) | 多孔/胞状金属的压缩试验；公开范围为孔隙率至少50%、环境温度、准静态；2011版于2022复审确认 | 金属压缩/吸能任务先检查材料、孔隙率和加载条件；不能直接认定PA12或动态冲击符合该标准 |
| [ASTM D1621-16(2023)](https://store.astm.org/standards/d1621) | 硬质胞状塑料的压缩性能，特别针对膨胀塑料 | 打印聚合物lattice仍需审查试样与材料适用性；不能把准静态结果替代冲击、蠕变和疲劳试验 |
| [ASTM E9-19(2025)e1](https://store.astm.org/standards/e9) | 金属材料室温轴向压缩 | 可用于基材表征的方法选择；必须考虑屈曲、鼓肚等因素，基材值不等于点阵整体值 |
| [ASTM D695-26](https://store.astm.org/standards/d695) | 刚性塑料的压缩性能，规定试样与低而均匀的加载条件 | 核实到的现行版本为2026版；不能把标准实心试样结果直接作为任意点阵的响应 |
| [ISO/ASTM 52909:2024](https://www.iso.org/standard/87956.html) | 金属增材制造件性能的方向和位置依赖 | 记录打印方向、取样方向/位置及报告条件；这是对既有测试方法的补充，不提供点阵通用强度门槛 |
| [ISO/ASTM 52910:2018](https://www.iso.org/standard/67289.html) | 增材制造设计的要求与指导 | 提醒检查设计/工艺限制；其公开范围不提供具体设计解或工艺材料专用阈值，不能将本题1mm杆径称为统一标准 |

本题库的尺寸容差、质量上限、目标曲线NRMSE、网格步长、候选数量和35/20/25/10/10权重均为**自定义合同**。试验标准不会替我们决定这些agent评分权重。

LAT-02/05/06/08可扩展为“选择试验方法及审查适用性”的任务，但现有合成数据不构成标准试验。LAT-21/23/24的几何检查也不自动构成AM工艺认证。LAT-22采用合成离散铰接杆系，并非上述材料试验标准所定义的实物试样实验。

## 已有超材料机器学习benchmark

### MetaGen / MetaBench（2025）

[作者论文](https://arxiv.org/abs/2508.17568)介绍参数化超材料数据与三类任务：结构重构、性能驱动逆向设计、性能预测。论文报告超过15万结构及模拟弹性性质等配对数据。它提供的是外部数据与研究协议，可补充我们的模型生成/逆向设计任务；模拟弹性指标不能直接证明塑性、冲击或疲劳性能。

### MetamatBench（KDD 2025）

[作者仓库](https://github.com/cjpcool/Metamaterial-Benchmark)及[作者论文](https://arxiv.org/abs/2505.20299)提供多数据集、多模型和多指标的统一研究评估，包含几何与有限元相关检查。作者报告5个数据集、17种ML方法、12项指标。它与我们的复杂工程工作流评测相关，但不能直接把其训练模型成绩换成Sol/ATLAS agent成绩。

## 我们采用与尚未采用的部分

本版本新增了这些外部参照和适用性记录，**尚未下载、运行或复现MetaBench/MetamatBench，没有借用它们的成绩。** 原创题仍使用自编合成数据，许可证不覆盖这些外部项目。

后续接入应先核实具体数据版本、许可、单位、边界、切分和评估实现，再冻结一个双方可访问的公开子集。保持原始协议时才能合理对照其报告；改变任务、几何表示、提示、模型预算或评估方法后须称为改编任务，另报结果。读过的测试答案不能继续冒充独立未见题。

建议采用三层证据：外部公开benchmark检验基础预测/逆设能力；本库复杂建模题检验工具使用与真实交付；独立保留任务检验新几何和新约束下的泛化。当前版本只完成第二层的题目与校验准备，以及第一层的来源调查。
