# 比较与评分协议 v0.1.0

## 测什么

公开开发集20题，五类各4题。测试工程agent的任务完成能力；不据此推断通用智力排名、材料真实性能、有限元求解器精度或生产安全认证。使用同一题目、输入、工具可达性和预算比较系统，而不是让一组使用私有答案库。

拟议主对照是普通助手 + GPT-6 Sol high 与 ATLAS + GPT-6 Sol high。两组同样能调用基础建模、读写、计算和检索工具。模型ID、实际reasoning effort、速度模式、提示词hash、工具schema、依赖与数据版本必须记录并在正式运行前核实；配置名写着high不算验证。普通助手使用最小任务指令，不人为禁止工具；ATLAS只增加其工程指令与工作流程。如果ATLAS拥有独占工具，应另列“系统集成”赛道，不能把差异全归因提示词。

原版产品界面也是可选体验对照，但工具、系统提示及运行器不同，必须单列，不能混入主对照。当前尚未冻结实际运行器和具体预算，也未启动模型调用。

## 每题如何发

1. 两组各建立新会话与干净工作目录，禁止读取其他案例答案、评分文件和历史聊天。
2. `export_case.py`默认只导出第一轮，可直接发给被测模型，包含当前`prompt_zh`、`inputs`、交付要求与来源卡。单轮题同时给数值schema，多轮题最终轮才给最终数值schema。
3. 多轮题用`--turn 2`/`--turn 3`严格依次导出并发送，每次等上一轮完成或触及预算。后续题包只给本轮修改量，不重述全部继承状态。不要将包含全部`followup_turns`的原始case对象交给模型。两组相同回复脚本，不因某组表现额外提示答案。固定后续轮次不算多余追问。
4. 基础数据和来源卡均随题给出。是否允许实时联网、哪些计算/CAD工具及版本必须对两组一致。来源卡不是论文复现实验；取不到全文不罚强行引用页码的替代能力。
5. 关键参数已知时不重复询问。预设故障题按输入事件做离线推演，不需要连接虚构服务器；CAD题要求真实交付，不能用离线推演代替。明确没有某项能力时如实报告并计交付未完成。
6. 每次保存原始聊天、工具调用、产物SHA256、实际模型/effort、时延、usage及人工介入。未经允许不能查看参考答案补写产物后还保留原分。

API模式按服务返回的输入/缓存/输出/推理用量记录真实费用；订阅模式不能把API价格当套餐扣量。若费用缺失，则效率费用分标“未测”，不当免费或满分。只报告可评的分项，不凑一个完整100分。该题库的离线脚本不调用模型，也不需要API凭据。

## 评分

四项质量维度：C工程准确性35、E证据20、D交付25、U省心10。`rubrics.json`每维内部points之和100。**v0.1每个检查是0或1，不使用临场半分**；多子条件检查须全部满足，遗漏写进review_notes。维度分为Σ(points×pass)/100。数值校验是C的部分证据，不能替代C/E/D/U的其他检查。缺少模型产物或检查记录不能预填通过。

效率10分仅在C≥0.8、E≥0.8、D=1、无致命错误时可得：

`efficiency = 5*min(1,time_reference/elapsed_seconds) + 5*min(1,cost_reference/actual_cost)`。

time_reference和cost_reference须按类别用独立试跑事前确定并冻结；同类两组共用，不可看最终结果再调。缺失或不可比成本时不发布完整100分，单列质量分/90和耗时、用量。零成本、零时延、负数或未知值必须审查来源，不能通过除零得到满分。

完整分：`35*C+20*E+25*D+10*U+efficiency`。每题列出的致命错误触发时该次总分0，保留分项诊断和原始输出。必要澄清不扣分，关键条件瞎猜会影响准确性。Markdown外观、答案长度、与参考措辞相似度不作为得分依据。

先用工具做计算、文件重读、拓扑及测量，再由隐藏组名的人审处理语义/证据；不能由被测模型自报分数。盲化组名不能保证审阅人完全猜不出系统，需要披露。评审分歧要记录，修改rubric时版本化并同时重评两组。

## 结果汇总与预算

第一步可用5题（每类一题）×两组各一次进行可行性/用量试跑。具体选择在运行前冻结，不能为争取好看比分只挑易题。每次最大总输入/输出token、墙钟、模型调用、工具调用和重试上限对两组相同；high推理token计入相应服务输出用量，不额外漏算。参考协议尚未给出未经试跑的强制数值预算。

正式可复现公开对照若采用20题×两组×3次，共120个任务运行，不是120个API请求。随机交错执行两组，记录失败和超时；自身恢复失败不能悄悄删掉。只按预先登记的外部共同故障规则成对重跑，保留原失败。

每题先平均3次得分，再比较差值：ATLAS高于基线超过3分为胜，低于超过3分为负，差值绝对值≤3分为平。五个类别均值等权汇总；报告分项、完整交付率、致命错误率、时间和用量。bootstrap以题目为配对单位，重复运行不算新的独立题；20题仍不足支持广泛泛化声明。

## 公开集与保留集

本次发布的20题及答案都是public_development。它们可用于逐指标优化，并公布真实公开集比分。**公开后在这些题上调优，再把同题称“最终盲测”不成立。**

最终未见题评测需由独立保管方另建题目、oracle和rubric并冻结hash。按结构族、几何模板和同源实验trial分组，不能仅改一个参数就当独立测试。开发者只看必要汇总；查看答案后，该保留集退役为回归集。现阶段没有创建或执行这套保留集。
