# ATLAS-Lattice-Bench

**面向 lattice / mechanical metamaterials 工程 agent 的公开中文测试题。**

v0.3.0 · 2026-10-07 · 20道基础题＋4道研究挑战＋8道数据库工程应用题 · MIT

工程应用的最终目标是**交付满足指定力学要求、可重建的lattice结构方案**。检索、性能估算和屈服反馈服务于选型与改型；交付须保留原始要求，给出结构规格、逐约束证据及裕度。已有数据支持的计算必须完成，缺少局部应力等证据只限制对应结论。降载或放宽要求可作为另列的备选，不能冒充原任务已达标；只罗列风险和未知项也不算完整设计交付。

现有核心题继续用于分项诊断；端到端工程设计题按“力学需求→结构方案→估算/验证→反馈改型→重新验收”组织。结论区分`passed_screening`（在声明模型和证据范围内满足原约束）、`needs_validation`（有候选但必要证据不足）与`infeasible`（在明确设计域和模型内已证明无解）。筛查通过不等于实物验证；数据不足不能给假PASS。

本项目评估 agent 能否正确用数据、做工程计算、交付可检查的几何文件，并在证据不足或工具失败时如实处理。两组比较须使用同一模型与推理强度；当前开发试跑选用 **GPT-6.1 Sol high** 与 **ATLAS + 同一 GPT-6.1 Sol high**。已有外部5题诊断试跑，但未形成完整题库得分，新增工程题尚未执行模型对比，没有已验证的优势结论。

原24题的数值为自编合成数据，保持原题意与参考值。新增8题的工程场景为合成，数据和反馈按附件provenance区分直接计算、N5外推估算及实际实验；缺失字段保持缺失，不以推测补齐。0.5%偏移屈服是题设整体曲线指标，不能据此定位局部首屈服。实验cohort缺少几何参数时，不能声称其验证某个指定slider/radius型号。

数据库附件只发布题目所需的可核查快照及来源哈希，不含完整私有工程目录或凭据。文献只以书目信息、链接和简短原创来源卡列出；其原许可不被本仓库MIT许可覆盖。各数据资产的来源与再分发范围须单独按其说明处理。

## 离线使用

校验题库和导出题包只需Python 3.10+标准库，无API key。实际完成CAD/数值挑战则需两组一致的建模、网格和数值计算环境：

```bash
python tools/validate.py
python -m unittest discover -s tests -v
python tools/export_case.py LAT-05 --output exports/LAT-05.json
python tools/export_case.py LAT-24 --output exports/LAT-24/packet.json
python tools/export_case.py LAT-25 --output exports/LAT-25/packet.json
```

`export_case.py`默认仅导出第一轮；用`--turn 2`或`--turn 3`依次导出后续轮次，**只在上一轮结束后发送**。首轮不含未来参数，最终轮才给最终数值输出schema。把当前题包交给两组；不要把整个仓库放入被测agent能读的工作目录，也不要让它检索参考答案。公开数据仍存在预训练污染风险，故这里只叫公开开发/复现集。

带附件的题包只复制manifest明确列出的输入并验证SHA256；LAT-24导出目录含原样损坏OBJ和元数据，不含干净网格或参考答案。`python tools/mesh_audit.py fixtures/LAT-24/damaged_lattice.obj --scale-to-mm 1000`可核对原始缺陷；该小工具不检查自交与表面保真，不能作为完整修复验收器。

被测agent输出`answer.json`后，可做部分检查：

```bash
python tools/check_numeric.py LAT-05 results/LAT-05/answer.json
```

该命令**只检查指定数值及单位，不产生完整工程得分**。格式为`{"energy_A_J":{"value":17.8,"unit":"J"}, ...}`；每题字段与容差均公开。建议JSON保留至少10位有效数字，正文可合理取整。文件存在、几何连通性、文献适用范围、恢复行为等仍须工具检查或人工审查。

## 评分与当前验证范围

工程准确性35、证据可信度20、任务交付25、省心程度10、完成效率10，总分100。**权重是本项目自定义协议，不是行业标准。** 三个赛道分别汇总。逐题检查只记0或1，按各维度权重归一化；致命造假、实质性单位错误或无证据工程PASS令该次总分为0。具体规则见[协议](docs/PROTOCOL.md)。

- 已完成：32题题干、分类标注的数据输入、固定多轮脚本、数值参考、验收清单、来源映射、离线结构/数值核算、LAT-24实际损坏网格输入，以及工程应用所需的哈希固定数据库附件。
- 未完成：32题完整模型跑分、新增工程题端到端模型试跑、CAD任务全套实际生成与几何验收、本题库对应的新实物制造或力学试验。
- 这32题全部公开，可用于优化ATLAS与复现。同题反复调优后的成绩不能称未见题泛化。
- 未来最终比分需要另建并封存未参与调优的题目；本仓库没有假装已存在的秘密测试集。

## 维护

`cases.jsonl`是公开规范题目，`reference_answers.json`是答案，`rubrics.json`是验收，`sources.json`是出处。修改后运行`python tools/render_docs.py`、校验和测试，并提升版本。原始算术oracle在`tools/oracles.py`，工程应用公式在`tools/engineering_oracles.py`，独立于参考值实现。`authoring/`仅是本地编辑辅助，不参与分发或离线运行；公开仓库不依赖它重新组装才能使用。
