# ATLAS-Lattice-Bench

**面向 lattice / mechanical metamaterials 工程 agent 的公开中文测试题。**

v0.2.0 · 2026-10-07 · 20道基础题＋4道研究挑战 · MIT

本项目评估 agent 能否正确用数据、做工程计算、交付可检查的几何文件，并在证据不足或工具失败时如实处理。计划比较 **GPT-6 Sol high** 与 **ATLAS + 同一 GPT-6 Sol high**。尚未执行模型对比，尚无排行榜或已验证的优势结论。

## 题目是什么

| 类别 | 题号 | 例子 |
|---|---|---|
| 数据与证据 | LAT-01—04 | 导出行与独立求解区分、拉压跨工况外推、逆向设计数据泄漏、预算选点 |
| 工程计算 | LAT-05—08 | SEA/CFE、有限尺寸拟合、热力Pareto、制造欠尺寸稳健筛查 |
| 几何与交付 | LAT-09—12 | TPMS、梯度/混合结构、杆系图与实体、多材料/参数化交付 |
| 多轮约束 | LAT-13—16 | 修改后保持尺寸、质量、工艺和既有要求；不覆盖旧产物冒充新结果 |
| 失败与恢复 | LAT-17—20 | 网格未收敛、文件哈希失败、带隙代理超域、热流数据缺失 |

新增研究挑战独立计分，不混入原20题总分：

| 题号 | 真实任务 | 必需证据 |
|---|---|---|
| LAT-21 | 带螺栓孔/电缆通道的锥形环状包络内自由点阵设计 | 至少两个实际候选、布尔检查、质量及局部特征、两级几何精度 |
| LAT-22 | 25节点/56杆几何非线性响应的逆向设计闭环 | 真实平衡求解、最多8个设计、目标曲线误差、独立细步长复核与CAD |
| LAT-23 | 限定代理模型下证明无解，再按授权最小放宽重建 | 解析证书、只改质量上限、实际并集体积与半径校准 |
| LAT-24 | 修复附带的真实损坏OBJ，保持孔道与单位 | 输入/输出SHA256、缺陷诊断、修复脚本、重读与拓扑/表面检查 |

LAT-22是自包含的合成离散杆系数值任务，**不是连续体FEA或实测材料**。LAT-24确有损坏输入附件。四题需要真实执行产物；数值锚点和文字答案正确，不能代替完整交付。新增目标尚未完成全套端到端模型试跑，难度与区分度仍待校准。

研究方向来自截至2026-10-07的一手论文抽样，包含非线性逆向设计、TPMS与异构连接、梯度结构、制造缺陷、动态吸能、有限尺寸、多材料及多功能优化。**这是选题依据，不是按论文数量或引用数得到的“热点排名”。**

所有题目数值为新编合成数据。没有复制论文数据表，也没有发布ATLAS的私有数据库、原始项目或凭据。文献只以书目信息、链接和简短原创来源卡列出；其原许可不被本仓库MIT许可覆盖。

## 离线使用

校验题库和导出题包只需Python 3.10+标准库，无API key。实际完成CAD/数值挑战则需两组一致的建模、网格和数值计算环境：

```bash
python tools/validate.py
python -m unittest discover -s tests -v
python tools/export_case.py LAT-05 --output exports/LAT-05.json
python tools/export_case.py LAT-24 --output exports/LAT-24/packet.json
```

`export_case.py`默认仅导出第一轮；用`--turn 2`或`--turn 3`依次导出后续轮次，**只在上一轮结束后发送**。首轮不含未来参数，最终轮才给最终数值输出schema。把当前题包交给两组；不要把整个仓库放入被测agent能读的工作目录，也不要让它检索参考答案。公开数据仍存在预训练污染风险，故这里只叫公开开发/复现集。

带附件的题包只复制manifest明确列出的输入并验证SHA256；LAT-24导出目录含原样损坏OBJ和元数据，不含干净网格或参考答案。`python tools/mesh_audit.py fixtures/LAT-24/damaged_lattice.obj --scale-to-mm 1000`可核对原始缺陷；该小工具不检查自交与表面保真，不能作为完整修复验收器。

被测agent输出`answer.json`后，可做部分检查：

```bash
python tools/check_numeric.py LAT-05 results/LAT-05/answer.json
```

该命令**只检查指定数值及单位，不产生完整工程得分**。格式为`{"energy_A_J":{"value":17.8,"unit":"J"}, ...}`；每题字段与容差均公开。建议JSON保留至少10位有效数字，正文可合理取整。文件存在、几何连通性、文献适用范围、恢复行为等仍须工具检查或人工审查。

工程准确性35、证据可信度20、任务交付25、省心程度10、完成效率10，总分100。**权重是本项目自定义协议，不是行业标准。** 两个赛道分别汇总。逐题检查只记0或1，按各维度权重归一化；致命造假、实质性单位错误或无证据工程PASS令该次总分为0。具体规则见[协议](docs/PROTOCOL.md)。

- 已完成：24题题干、合成输入、固定多轮脚本、数值参考、验收清单、来源映射、离线结构/数值核算、LAT-24实际损坏网格输入。

## 维护

`cases.jsonl`是题目，`reference_answers.json`是答案，`rubrics.json`是验收，`sources.json`是出处。修改后运行`python tools/render_docs.py`、校验和测试，并提升版本。原始算术oracle在`tools/oracles.py`，独立于参考值实现。
